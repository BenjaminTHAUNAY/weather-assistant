# Weather Analysis Assistant

A Python-based weather agent that uses external tools (APIs) to provide current weather and forecasts.

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Get API key from OpenWeatherMap
4. Create `.env` file with your key

## Usage

```bash
python main.py --query "weather in Paris"
python main.py --city Riga --forecast
